# Multiplayer Mario Style Game

Modern browser-based multiplayer platform racing game.

## Features
- LAN hotspot multiplayer
- 1 to 5 players
- Mobile browser controls
- Modern graphics
- Google login
- Powerups and skills
- Shop system
- Leaderboard
- Single player practice mode

## Tech Stack
- Frontend: Phaser.js
- Backend: Node.js + Express
- Multiplayer: Socket.IO
- Authentication: Firebase Google Auth

## Project Structure
- client/
- server/
- shared/

## Planned Gameplay
Players race through obstacle maps while collecting boosts and using skills against opponents.
